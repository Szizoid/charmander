### charmander <sup>`v0.4.2`</sup>

Type accented letters and special characters on Wayland without leaving the keyboard:
hold a key, tap a modifier, pick a variant. No popup hotkeys, no context switching.
Works below the compositor (evdev + uinput), so it behaves the same in every app.

### Описание

Набирайте буквы с диакритикой и спецсимволы в Wayland, не отрываясь от клавиатуры:
зажмите клавишу, нажмите модификатор, выберите вариант. Никаких отдельных хоткеев
и всплывающих окон, никакого переключения контекста. Работает ниже композитора
(evdev + uinput), поэтому ведёт себя одинаково в любом приложении.
